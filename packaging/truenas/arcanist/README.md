# Arcanist

[Arcanist](https://github.com/linkfast/arcanist) is a self-hosted music server to stream your music library to all your devices.

On first start, open the web UI and follow the setup wizard. When opened from another device it asks for the setup code
printed in the app logs (also saved as `setup-code.txt` in the data storage). Add `/music` as a library.
